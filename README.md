# hoanglan9569.github.io

Redirects only. The agentic-qa repository moved to the Releaseworthy organization on 2026-10-18, and GitHub does not
redirect GitHub Pages after a transfer, so this user site forwards the old report links:

- `hoanglan9569.github.io/agentic-qa/` goes to `releaseworthy.github.io/agentic-qa/` (`agentic-qa/index.html`).
- Every other path under `/agentic-qa/` goes to the same path on `releaseworthy.github.io` (`404.html`).

`.nojekyll` keeps this README from being published as the site root, which stays a 404 page.

Do not create a repository named `agentic-qa` under hoanglan9569: it would delete GitHub's redirect to
`Releaseworthy/agentic-qa` and take over the `/agentic-qa/` path from this site.
